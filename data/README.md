# Data

`synthetic_weekly_kpis.csv` is generated by `business_review.synthetic` with a fixed seed. It contains fictional weekly KPI actuals, planning targets, source row identifiers, and injected anomaly labels used only for evaluation.

The file does not contain customer-level records, company data, internal table names, production thresholds, or exported dashboard values. Delete it and run `make reproduce` to regenerate the same artifact.
